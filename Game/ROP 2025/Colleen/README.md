# Sore Loser
A True Blue varsity athlete is found dead in his apartment, and while the apparent cause seems to be via a steroid overdose, things don't seam to be adding up...


## Scene + Current Evidence
This scenario takes place within the dining area of a student dorm shared by the victim and his roommate.

`Main Area`
- **Blood drips on floor**: blood sample collection and presumptive test 
- **Blood stain on carpet**: blood sample collection and presumptive test, carpet sample collection (with scissors) that leads into luminol sequence 
- **Needle on dining table**: item collection (to be analyzed further in the Lab)

`Upper Cabinet`
- **Fingerprint on cabinet door**: fingerprint collection
- **Tylenol on cabinet shelves**: item collection (to be analyzed further in the Lab)
- **Various vitamins**: player is able to observe shapes the kinds of pills and vitamins the victim usually takes

`Lower Cabinet`
- **Rat poison**: item collection (to be analyzed further in the Lab)

`Trashcan`
- **Steroid vial**: item collection (to be analyzed further in the Lab)
- **Pillbox with some pills**: item collection (to be analyzed further in the Lab)
